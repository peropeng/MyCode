## 保留与续跑

[ＲQ1索引](01_根因排序_RQ1/保留实验索引.md)与[RQ2索引](02_运行故障恢复_RQ2/保留实验索引.md)按研究问题列材料、下一动作及完成条件。44组表示归档范围，不是待运行实验数，不再按恢复文件多少决定投入。

已完成旧实验不重跑。未完成且能直接补齐当前研究问题的记录，可以在原输入、代码、后端、参数和累计资源可核对时续跑。改变方法或条件另建开发记录，保留旧问题曝光，不能拼接成绩。原档案、模型、固定输入和必要依赖继续保留。

15次训练和420次恢复属于旧版工作量估计，当前定稿未将其写死。RQ1先审查已有本方法和StepFinder各3份模型能否复用；RQ2不从旧次数倒推固定模块和运行队列。机器决策见[用途优先级](../02_工作区/01_工程/manifests/experiment_use_priorities.json)，历史评估仅作来源保留。

本轮按新执行任务先核对已有终态，再补真实缺项。固定120题Binary Search复用已完成记录，RQ2已补同一共同问题的EnAgent独立验收并通过，四方法生成均不重跑。
