# v6 原文语义提取资格审查：当前提取器未通过

结论：当前紧凑输入、prompt、schema 与 `100+24*n_steps` 输出额度组合没有产生可供 A/B 使用的完整语义图，资格结论为 **NO-GO**。固定 12 条一次性请求中，5 条因输出长度截断而不是完整 JSON，另 7 条虽可解析 JSON，但目标、表达式、命题及关系数组全部为空。未扩大到 731 条、未新编码、未训练或调用固定基线。

这一结论只针对本次具体提取器。它不证明 Flash 普遍无法提取结构，也不检验或否定尚未实现的来源族预算、目标组合检查两个机制。独立审阅通过的是调用前的输入和财务安全性；语义质量不能由该 PASS 或 JSON 合法性代替。

## 输入、选择和版本边界

公开 task、原角色名及 content/action/thought 是所有潜在后续条件的共同输入升级，本身不计为 A/B 创新。只读公开列确定合法开发池 731 条、716 任务组；未读取步骤 Gold、责任解释、正确答案、基线输出或旧错例。source/domain 仅用于预定抽样与报告，未进入实际 API 消息。

12 条按预定公开 hash 选择：5 个非空 domain/source 单元各选 2 个不同任务组及其固定代表，再加入剩余不同组中原公开输入 UTF8 字节数最长的 2 条。不是按错误、收益或新输出选样。完整原文字段逐字符可还原；JSON 内嵌参数字符串保持原样，不假装已经解析或执行。

完整本地账本约 5.748 MB；最终稀疏 wire 约 2.415 MB，省去的是可重建语法包装和重复存储，全部原字段保留。全量有 167/731 条包含直接 Python 调用语法，694 条有 opaque arguments 字符串，其中 441 条含可另行 JSON 解码的 arguments；这些只是语法覆盖，不能当成真实执行或语义可用性。

v1/v2/v3 的原输出与对应源快照均保留；实际付费使用的是 qualification_cpu_v4 及冻结 runtime_binding。CPU 检查包括 17 项 schema/字段/引用测试与 12 项财务/锁测试。

冻结 runtime_binding SHA256：`c6da9d738abbc3bf00e37c90ed7c12b6ddb27ab148c190d5ce44945f7202422d`。

## 实际费用与余额守卫

12 次请求共 42,520 输入 token、3,153 输出 token。按返回 usage 和峰价计算的已结算上界为 **0.09922528 元**；若全部输入按未命中缓存计峰价，则为 0.110264 元。末次余额回执为 [账户数值已隐去] 元；回执可能延迟或取整，不能据此视为免费调用。

每次调用均串行执行：共享独占锁内重载账本，先拒绝任何缺少有效结算的 reservation，再核 source/payload/sample/stage/cap 绑定；实时查询调用前后 CNY 余额，并按完整 1,048,576 输入 token 的峰价加本次输出上限预留，保留至少 1+0.02 元。12 条均已结算，无未知费用或自动重试。

真实 pilot 的最大输入 token/字节比为 0.411117，高于历史规划比率。按更新经验值、额外 128 framing 及剩余全部输出上限计算，719 条剩余队列预测还需 5.517410 元；同时检查实时与累积支出后的预留门，预测不通过。经验比率不是严格 tokenizer 上界，且当前语义资格已经失败，因此没有扩展授权。
