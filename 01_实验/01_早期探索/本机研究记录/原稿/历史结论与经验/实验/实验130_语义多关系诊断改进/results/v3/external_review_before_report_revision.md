## 设计与隔离边界

- `model_v3.py:42–57` 继承自有 v2 的 `model.py`，保留 183→96 投影、两层四关系局部消息、原 head，在两局部层之后、readout 之前增加一层全局模块。没有导入或调用 StepFinder 模型。
- `model_v3.py:9–17` 使用 hidden96、2 heads、每头48维，QKV 为96→288线性投影；四关系 additive bias 为形状2×4的可学参数，初始化精确为0。
- `model_v3.py:19–30` 对拼接的真实节点计算候选 query 到所有 key 的 scaled dot-product。`record_index` 相同才可参与 softmax，不同记录的 logit 置为负无穷；同记录包含自身，所以不存在全部被mask的正常行。`runner_v3.py` 的 record index 仍按每条轨迹分配，不按 task_group 合并，因此同组的两条轨迹也不会互相读取。
- `model_v3.py:26–28` 对四种原有稀疏关系建立 bias mask，同时与 `adj.valid.bool()` 相与；邻居 padding槽默认指向0，经过 valid掩码后不会伪造边。注意力输入只含实际节点，没有轨迹长度补齐节点；同batch其他轨迹不能影响当前轨迹的softmax分母。
- 全局模块是同轨迹完整可见步骤注意力，不是因果/在线 attention，协议已明确包含 self 且非邻接步骤也可参与。这与本任务离线故障诊断范围一致。
