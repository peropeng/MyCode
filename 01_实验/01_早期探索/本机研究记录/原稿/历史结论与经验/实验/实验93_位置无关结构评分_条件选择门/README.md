# 实验93：位置无关结构评分条件选择门（阶段1开发探针）

本目录只记录阶段1开发探针，不是最终确认实验，也不是第二个 GO。它验证一个且仅一个机制：当 `fewer_explicit_errors` 的两个候选显式错误数相同，且 Exp63 的冻结结构模型在严格 UUID-OOF 上具有足够 margin 时，才把该行从 Base 路由到结构评分；其他行回退 Base。

本阶段只使用已经消费过的 Exp63 开发资产和 Exp70 的 `planning_single_hard` 结果资产。没有 API、网络、语义 Judge、文本融合、第三模块、额外候选或最终确认输出。

## 先说结论

结论是：`STOP_EXP93_FIXED_CONDITIONAL_GATE_ONLY`。

这不是“结构方法全部 NO-GO”，也不是“Exp63 的正信号被推翻”。Exp63 的严格 OOF 上确实有正信号，但选出的固定门在 Exp70 上几乎不路由，而且被路由行逐行都没有改变 Base 的预测，因此不能称为可行的跨集门控机制。

## 门的选择（只在 Exp63 OOF 上完成）

Exp63 OOF 有 361 行、121 个 UUID。margin 定义为冻结 LogisticRegression `decision_function` 的绝对值，候选固定为全 OOF margin 的 `no-margin`、0.50、0.65、0.80 分位点。候选先要求路由覆盖率至少 10%，再最大化 UUID 宏平均 utility；utility 平局时选择更保守的较大阈值。没有使用 Exp70 标签选阈值。

|候选|阈值|Exp63 路由覆盖率|UUID 宏 utility|相对 Base 的 pooled 差值|资格|
|---|---:|---:|---:|---:|---|
|no-margin|—|51.25%|+2.204pp|+2.216pp|通过|
|q0.50|1.047396|12.74%|+4.683pp|+4.709pp|选中|
|q0.65|1.570197|9.42%|+3.030pp|+3.047pp|覆盖率不足|
|q0.80|2.346852|5.54%|+1.653pp|+1.662pp|覆盖率不足|

因此阶段1没有因为 Exp63 OOF 的点估计是正的就直接宣布 GO；它把 q0.50 作为唯一、事先规定的外推门。

## Exp70 外推结果

Exp70 每个方向 seed 有 158 行、97 个 UUID。该门要求两个显式错误数相同，并且 margin 至少为 1.047396。

|方向 seed|Base 准确率|Base+A 全量|Base+A+G 门控|门相对 Base|门路由行数|门路由覆盖率|
|---:|---:|---:|---:|---:|---:|---:|
|20260822|64.557%|60.127%|64.557%|0.000pp|2|1.266%|
|20260824|55.696%|61.392%|55.696%|0.000pp|2|1.266%|
|20260825|59.494%|58.228%|59.494%|0.000pp|2|1.266%|
|合并（474 行）|59.916%|59.916%|59.916%|0.000pp|6|1.266%|

门的 paired UUID bootstrap（97 个 UUID、10000 次、95% CI）为 `[0.000pp, 0.000pp]`；UUID better/worse/tie 为 `0/0/97`。选中的门在 474 行上逐行等于 Base。6 个被路由行中，结构预测和 Base 的正确性也全部相同；所以这不是“置信区间暂时跨 0”，而是门没有实际改变决策。

匹配覆盖率的随机门作为负对照路由同样数量的行，合并点差为 `+0.422pp`，UUID bootstrap 95% CI 为 `[-0.172pp, +1.890pp]`。它的点估计也跨过 0，不能支持条件结构机制；它反而说明在只有 2/158 行的极低覆盖率下，微小差值可能只是随机波动。

删除 A 后的 `Base+G` 在全部 seed、全部行上逐行等于 Base，删除等价审计通过。三次方向的 chosen-first 比例分别为 51.266%、50.000%、47.468%，均在 `[45%,55%]`；API/network 均为 0，UUID 没有跨 OOF fold 泄漏。

## 为什么必须停止这个固定门

这里有可核验的、绝对的停止理由：

1. 选出的 q0.50 门在 Exp70 的 115 个 Base 不确定行中只路由 2 行，即 1.74% 的不确定行、1.266% 的全部行；它没有达到开发期希望保留的有效覆盖范围。
2. 更强的逐行证据是：这 6 个跨 seed 的路由行上，结构模型没有一次改变 Base 的预测，最终 `Base+A+G == Base` 行向成立，故不可能产生准确率提高。
3. 随机同覆盖率门出现了一个很小且 CI 跨 0 的正点差，说明这点规模的变化不足以证明门的机制价值。

所以停止对象只能写成 `STOP_EXP93_FIXED_CONDITIONAL_GATE_ONLY`：停止 q0.50、Exp63 OOF margin、Exp70 tie-only 这一个固定组合。它不计作 `TRUE_METHOD_NO_GO`，不抹掉 Exp63 的 OOF 正信号，也不允许据此声称第二个 GO。若继续研究结构评分，应另行冻结一个有明确可观测机制的条件化设计；本目录不自行增加模块或打开新的封存确认资产。
