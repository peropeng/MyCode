# P50：神经轨迹证据与语义判断融合

本轮“神经轨迹证据 A + 局部／全局／持续影响语义证据 B”命中 23/32（71.875%），比单独 A 和 B 各多一条，但仅追平最好缓存文献基线，低于既有 P44 固定融合的 24/32。两个新模型均收敛，固定科学门槛失败，淘汰本轮组合。

## 信息来源与训练边界

P48、P49 的语义融合主要使用三个模型生成的排序，C 仅用于精确分数平局。本轮将自有神经轨迹模型 C 的分数作为额外预测信息，并用共同的 64 条合法 FIT 样本学习融合。

训练端使用 P4 已封存的三折组外 C 分数：每条记录的任务组都不在生成其分数的模型训练集合中。评测端使用原 P3 全量 FIT 训练所得 C 的冻结分数。直接从既有公共 `text_public_features.pt` 提取 `scores` 字典，复用其逐轨迹居中／RMS 标准化结果；不读取旧的含 Gold 预测文件，不重新推理神经模型，不以训练内高分替代组外分数。全部 64 条 FIT 的成员排除、形状、有限性与 32 条评测分数可用性均有只读收据。

三个语义特征仍为 L、G、P 各自的负对数名次；新联合模型使用四列 `[zC,xL,xG,xP]`，A 对照只用第一列。各列尺度只由共同 FIT 集合按任务等权计算，语义三列尺度与 P49 的三参数 B 对照严格相同。B 直接复用 P49 对照，不重训。

两个新模型共享 P48 的 CE 加 0.2 倍平均 pairwise softplus、单位高斯正则目标，以及固定零初始化、无截距、无 C 偏置、float64 单线程 LBFGS。只各拟合一次，不重新分折、不换源分数、不扫描正则或验证权重。监督仅使用 P48 已合法保存的 64 条 FIT 标签，没有新的源 FIT 标签访问。
