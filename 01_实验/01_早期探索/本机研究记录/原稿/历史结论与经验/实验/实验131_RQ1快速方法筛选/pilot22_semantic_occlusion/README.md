# P22 现有 C 模型的语义遮蔽敏感度

本轮使用已经训练好的C模型，提取小维度的模型敏感度作为校正输入。fit327条记录各用其已有P4 heldoutfold C及对应公开特征，保留OOF隔离；40验证与32开发使用原P3 fullfit C。输入和原模型被冻结，逐条复现归一化后的C缓存分数，误差需不超过1e-6，随后保留缓存分数字节不变。

每个干预仅将当前步骤的steps与content两种128维语义向量置零，其余步骤、任务、角色、结构与pair特征固定。每个步骤独立遮蔽，原始logit差除以原始分数的总体标准差，遮蔽后的分数不重新归一或softmax。

对干预i的响应扣除全部非i步骤的平均值。A是本步居中响应的正、负两维；B_future与B_past分别取未来侧、过去侧居中响应的正、负均值。空方向与n=1全零。常数全局logit平移因此不会形成特征，只有局部响应变化也不会形成非局部特征。

B_future表示相对于全部非本步平均值的未来侧响应。过去侧变化也可能通过中心化影响未来侧符号，AB_past_control用于方向匹配比较。本轮是保留结构与pair输入的部分语义干预，不能据此证明真实执行系统的因果关系或绝对下游传播，也不是实际删除对话步骤。

三类特征各用一个fit-only RMS行范数尺度，按320组、记录与步骤等权计算，包含零行，下限1e-4；两维补零到1024。新拟合A_local、B_future、AB_future、AA_duplicate与AB_past_control五个模型，缓存原C。AA两个头用同一A；AB_past_control用A与单独缩放的B_past，其余B模型只用B_future。每分支有效参数2，注册容量2048，尾部保持精确零。

残差头的ranking CE+.2mean_nonGoldsoftplus、组权重、每activehead L2、CPU float64、零初始化、LBFGS300/375与梯度1e-7门槛保持不变。缓存P3/P4 C原先使用CE训练，残差头的pair项来自既有项目目标，不能视为缓存C曾使用该目标。五头全部封存后才一次评估32开发与描述性40验证。AB_future至少25/32且严格超过C/A/Bfuture/AAdup/ABpast及四缓存基线，并全部收敛，才能通过探索筛选。

已有四模型最大形状公开探针及其loader证据原文复制，不重复资格链。公开特征构建包含加载、基线与全部遮蔽、保存，实际预算600秒；五头共同训练预算600秒。记录从公开构建开始到结果的执行时间和1800秒预算，另从方案登记18:04:25.677 UTC起记录包含实现与审查的完整本轮时间，均保留18:24 UTC截止。研究累计仍从16:24连续计时。RQ1继续、RQ2暂停，重复开发筛选与描述性验证不构成独立确认。
