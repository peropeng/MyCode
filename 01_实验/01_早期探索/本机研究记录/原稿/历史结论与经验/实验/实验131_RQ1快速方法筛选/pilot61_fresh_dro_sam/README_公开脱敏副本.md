# P61：从共同随机初始化训练长度分组 DRO 与 SAM

“轨迹长度分组 DRO A + SAM B”在固定开发集命中 **17/32（53.125%）**，决定为 `STOP_FIXED_FRESH_LENGTH_DRO_SAM`。固定科学门槛未通过，关闭本轮固定训练方案，不追加学习率、分组、rho、eta、种子或选模变体。本轮的直接对照是同一随机初始状态、同一训练数据的 C_FRESH_ERM；此前续训结果只作为缓存参照，不能用不同初始化混淆优化方法的效果。

## 两种方法如何组合

A 在原 320 个 FIT 任务组上定义五个大小相等的训练组。每个任务组按其全部 FIT 记录的步骤数计算精确分数形式的平均长度，以平均长度、原任务组 ID 排序，每 64 组划成一个长度桶。哈希对照以固定盐 `exp131-p61-shuffled-groups-v1|` 加任务组 ID 的 SHA256 排序，同样划成五桶。分组只用公开 FIT 信息，不用验证集、开发集或标签，也不新增领域、来源或注入标记。原有 V22 公开训练权重仍保留。

对包含 B 个任务组的小批，CE_i 是第 i 组内部记录交叉熵的平均，w_i 是原组权重。每桶贡献为 `L_h=(5/B)*sum(w_i*CE_i)`，缺席桶为零；网络目标是 `sum(q_h*L_h)`。q 由五个 float64 对数权重 softmax 得到，初始均匀，因此数学上恢复原加权 ERM 目标。浮点加总顺序不同不保证逐位相等。每次外层参数更新后，才用首次、未扰动前向的分桶损失更新一次 `z += 0.1*L` 并减去 logsumexp 归一。C 与单独 SAM 固定使用均匀 q。

原登记曾写桶内加权均值更新，随后在任何 P61 实现、监督和执行之前，通过保留原文的数学附录改成上述 5/B 贡献，使网络目标与对抗权重更新一致。该修正发生在 P60 结果之后、P61 结果之前，不是依据 P61 表现调参。

B 使用 SAM：先保存活动参数的精确副本与 CPU RNG 状态；第一次前向得到未经梯度裁剪的 g，按 `epsilon=0.05*g/(global_L2_norm(g)+1e-12)` 临时扰动活动参数。第二次使用相同小批、q 和 dropout 随机状态，在扰动参数下求梯度。随后逐项复制恢复原参数，再执行 clip1 和一次 AdamW 更新；异常路径也必须精确恢复。第二次前向实际结束的 RNG 状态要与第一次一致，不能仅通过事后强制重设来假装验证。没有在扰动参数上更新 AdamW 矩，也没有第二次 q 更新或第三次前向。

主条件同时使用长度 DRO 和 SAM，哈希分组对照保留同样的 SAM、参数规模及 q 更新方式，用于检查长度分组是否有增量价值。这是普通消融，不能直接证明因果机制。SAM 每次外层更新有两次训练前向，与 C／A 的单次前向计算量不同。
