# P14 普通RBF原型非线性残差

该方向在P13出结果之前于17:04:24 UTC固定，依据P12的validation线性未来读出25/40与C27/40检验非线性表征。输入完整复用P13已经缩放的过去A128与未来B128，不增加编码或挑选开发错误。

每个分支由320个fit组公开行确定原型：先算等record/等step组均值，取该组最近的非零观测行，按record_id/step打破相同距离；组键排序后对浮点值相同的候选去重。第一个原型取最近候选均值者，再确定性farthest-point取最多64点，第一索引打破相同距离。零组仅不产生候选，仍保留在数据和尺度统计中。

带宽固定取所有候选无序不同点正欧氏距离的通常中位数，偶数中间两值平均，floor1e-4。phi_j(x)=exp(-distance(x,z_j)^2/(2h^2))-exp(-norm(z_j)^2/(2h^2))，原全零输入显式映射为零。随后用fit组等组/record/step的单RMS尺度归一，零行保留，再填充至1024。A/B各64有效坐标，原型、代表索引、bandwidth和尺度均保存。

这是普通RBF原型特征，不含Gram白化，也不是Nyström近似。表征维度与L2几何均改变，结果不应单独归因于语义机制，不宣称文献创新。只新拟合A_RBF、B_RBF、AB_RBF三个头，C与P13线性比较为缓存参考。
