# P56：固定候选提议与穷举逐对判断

本轮“神经／语义候选提议 A + 逐对比较排序 B”命中 19/32（59.375%），同一逐对流程作用于 C 候选的 B 对照命中 17/32（53.125%）。两者均比 P51 对应的三候选直接判断少命中 2 条。本轮 125 份新响应全部有效，没有循环胜负；固定门槛失败，停止此方案，决定为 `STOP_FIXED_PAIRWISE_ADJUDICATION`。

## 方法与固定比较规则

完全复用 P51 的原始任务、完整轨迹、C 与 P50 完整排序及前三候选。A 为缓存 P50 神经／语义融合排序，B 对照使用 C 的前三候选，A+B 使用 P50 的前三候选。每个候选集合都比较全部三个无序候选对。

每次比较使用原 P37 系统提示和完整公开轨迹，只把可选步骤限制为当前两个候选，并按原始步骤索引升序列出。模型看不到候选分数、排名、条件名、训练示例、P55 生成论据或评测标签。沿用严格 `chosen_step` 解析器、温度 0、关闭 thinking、256 token 上限以及一次调用、不重试规则。

每个集合的三次比较都有效时，胜者各得一分，三个候选按胜场数降序排列，平局按各自原 C／P50 排序处理，再附上原排序中未入选的其余步骤。三者循环胜负时各得一分，预定解码会保留原候选顺序；本轮实际没有发生循环。

任一比较响应无效会使依赖它的整个条件记为未命中，但仍执行该集合其余事前列出的比较，不根据部分结果改变调用计划。未知、未运行或资源中止会禁止完整 32 条评价。本轮没有触发这些分支。有效结果的平局规则与无效结果不回退是不同情况。

63 个有效三候选集合产生 189 个比较消费者，按本轮精确请求哈希共享为 125 次调用，共复用 64 次。另 1 个 A+B 位置继承了无效 P 排序，不执行比较并保留为未命中；对应 C 候选仍正常执行。调度固定为记录编号升序、先 C 集合后 A+B 集合、集合内按候选对字典序，不跨轮复用模型响应。

## 解释边界

逐对提示排序已有 [PRP](https://aclanthology.org/2024.findings-naacl.97/) 等研究，逐对与集合判断的效率取舍也有 [setwise ranking](https://arxiv.org/abs/2310.09497) 研究。本轮不声称提出新的通用排序算法，也不把文档检索中的效果当作责任归因证据。

本轮在接口全部有效的情况下仍低于对应直接判断和原候选提议，不支持这个固定逐对流程的效用。逐对比较增加调用次数并改变判断上下文；C 候选上的匹配对照不能单独证明机制，也未消除与直接判断的计算量差异。前三候选来自之前开发探索，这 32 条仍是反复使用的开发数据，不能提供独立胜出证据。

核心结果见 `results/used_development32/comparison.json`；事前候选对计划、共享映射、比较库、公开预测封存、原始响应、连续账本及独立审查均随附。下一轮仅按事前登记检验一次冻结角色顺序与已保存 B 的组合，不新增调用或训练。RQ2 继续暂停。
