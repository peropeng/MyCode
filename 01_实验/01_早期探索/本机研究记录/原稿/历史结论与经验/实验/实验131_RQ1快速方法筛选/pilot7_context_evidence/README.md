# P7：整轨迹上下文编码公开预检 STOP

本轮在公开编码预检阶段停止，没有训练模型或读取本轮 fit/validation/development Gold，因此没有 P7 的 A/B 准确率。RQ1 仍在继续，RQ2 保持暂停；上一轮实际主方法指标仍是 P6 AB 17/32（53.125%），不能当作 P7 结果。

方法拟在保持原 LegacyV19 C 输入与结构的基础上，增加原始 token 的过去/反向未来上下文减同位置 unary 差分，各配一个零初始化无偏置 1024→1 头。六条件为 C、A、B、AB、AA_duplicate、AB_length_only。独立包 token IDs、分隔符和池化位置已冻结；399 条公开轨迹共 4175 步，每方向 723015 token，最长 21177，未截断或删除记录。四组 fit-only 全局 RMS 规则已事先声明，但未计算实际 RMS，也未冻结训练预算。

| 公开尝试 | 冻结预算 | 实际时间 | 结果 |
|---|---:|---:|---|
| BF16 原路径 | 90s | 26.672s | 5/5 完成；不同长度前缀数值契约失败 |
| FP32 Efficient | 180s | 60.953s | 5/5 完成；前缀/同形状检查失败，独立固定形状合成输入重复不稳定 |
| FP32 MATH、query128 | 180s | 180.062s | 4/5 完成后超时；未进入模型因果/前缀检查 |

MATH 的 21177 token 样例耗时 105.422s。固定 query128 对小规模 dense MATH 的合成等价检查通过，不能代替未完成的模型检查，也不能将超时改为 GO。所有尝试沿用冻结阈值；本轮不延时、不换 block 大小、不再次编码。STOP 是具体实现的数值/资源边界，并未否定信息假设或提供方法性能负证据。

CPU 模型检查通过 10 项：六条件共有 545906 个注册参数，新增 2048 个无偏置头参数；原 C 初始化、dropout RNG、零头得分、固定非零头路由和禁用梯度均验证。实际旧 v21 目标是 CE 加 0.2 倍负例 softplus 均值，原设计中的 pure CE 表述在训练前由 `pretraining_loss_correction.json` 更正。按该真实目标，69 个共享参数梯度与旧 C 四槽目标误差最大 5.96e-8。

`stop_result.json` 是结论与边界，三份 `public_preflight*_protocol.json` 和失败 receipt 保留实际源码/输入哈希，三个 `*_preflight_attempt/manifest.json` 封存各次快照。两个后续尝试的原始公开向量保留为 `.pt`；BF16 最初失败路径没有保存原始向量或每次调用日志，其不可恢复范围已明确记录，未重跑补齐。`audit/` 保存独立审查，`delivery_manifest.json` 统一绑定本轮交付文件。验证仅检查保存的字节、JSON、哈希与上述 CPU 合成行为，没有新推理、训练或 Gold 读取。
