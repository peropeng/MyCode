# P58：局部与全局教师引导的负例续训

“局部证据教师引导 A + 全局纠错教师引导 B”命中 **22/32（68.75%）**。五个模型都实际训练了 4 轮，但按事前规定的验证规则均选回共同初始检查点；因此没有新增学习增益。主条件低于最强文献缓存基线的 23/32，也低于最佳自有缓存的 24/32，未达到固定 25/32 门槛，决定为 `STOP_FIXED_TEACHER_GUIDED_CONTINUATION`。不追加学习率、损失权重、训练轮数或选模规则变体来改变本轮结论。

## 检验什么

本轮将已保存的语义排名用于训练端，检验它们能否帮助原神经模型区分真实责任步骤与容易混淆的错误候选。所有条件从 P3 C 的同一完整检查点继续训练，共注册 633,619 个参数，使用原公开特征和缩放器，没有重新编码文本。共同初始化的 SHA256 为 `1eabc9a9174513e57596eeaab086e2ac6aa3dd700df2905c27be18bc09a23f0b`。

教师只来自 P48 中 64 条原训练记录的局部／全局排名。对真实步骤 g 以外的候选，按教师排名的倒数归一成固定权重 q，再计算 `sum(q[j] * softplus(score[j] - score[g]))`。单候选记录的附加损失为零。没有按教师是否正确筛选记录，也没有温度、截断排名或可学习混合权重。

原 320 个训练任务组、327 条记录均保留监督交叉熵。组内先按记录平均，再应用原 V22 组权重。附加损失只覆盖有教师记录的组，并按 `W_all / W_teacher = 320 / 61.33333333333333 = 5.217391304347826` 归一；此比值只依赖公开训练成员和既有权重。

| 新条件 | 训练目标 | 实际轮数 / 更新次数 | 选中轮次 | 开发命中 / 32 |
|---|---|---:|---:|---:|
| C_CONT | 原监督交叉熵 | 4 / 80 | 0 | 22 |
| A_LOCAL | 交叉熵 + 局部教师负例损失 | 4 / 80 | 0 | 22 |
| B_GLOBAL | 交叉熵 + 全局教师负例损失 | 4 / 80 | 0 | 22 |
| UNIFORM_CONTROL | 交叉熵 + 同批错误候选等权损失 | 4 / 80 | 0 | 22 |
| **PRIMARY_AB_LOCAL_GLOBAL** | **交叉熵 + 局部、全局损失的平均** | **4 / 80** | **0** | **22** |

四个含附加损失的条件共用系数 0.2。A+B 取平均而非相加，避免仅将附加损失加倍；均匀对照用于区分教师排名信号与一般正负候选比较损失的作用。五个最终选中模型的状态均逐项等于初始状态，所以结果不支持本轮教师引导带来增益。

## 固定训练与选模

使用 CPU float32 单线程、seed20260816、各轮相同的 `seed + epoch` 组打乱顺序。五个条件均使用新的 AdamW 状态，学习率和 weight decay 都为 0.0001，每批 16 个任务组，活动梯度统一 clip1。固定最多 8 轮、连续 4 次验证任务组 Top1 未严格提高则停止。

共同初始检查点 epoch0 的 40 条验证成绩只计算一次，并允许被选中。五个条件都选择最早达到最高验证 Top1 的轮次；实际均以 `patience4` 停止，选中成绩为 27/40，与初始成绩相同。选回 epoch0 不等于没有训练：本轮共执行 400 次参数更新，保留 20 份训练轮次检查点和 5 份最终选择，以及完整训练历史。固定预算筛选不能视为充分收敛证明。

本轮在源码冻结后复用已核实的 327 条训练标签和 40 条验证标签缓存，未再次调用源 FIT／VAL 标签读取器。训练标签用于交叉熵与排除真实步骤；验证标签只用于检查点选择。因此这是使用监督的神经续训，不能写作“零 FIT Gold”。独立元数据检查只核访问回执、成员与文件哈希；执行器在冻结后再核对缓存实际成员。
