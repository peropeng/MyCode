## 方法和对照

A 仅接收原任务文本，生成简短的要求、约束和可检查事项，不读取轨迹、候选排名、标签或其他条件输出。B 仅接收原始步骤序列，整理信息由谁产生、如何复用和发生何种变化，不要求它直接判断责任步骤。B 的原始步骤可能引用任务文本，因此不能将它描述为完全不含任务信息。

所有辅助记录都只是模型生成的判断，可能错误。三个判别条件分别接收 A、B 或二者，并使用同一个 P37 系统提示和严格选择解析器，看到完整原任务、全部原始步骤和按原编号排列的全部候选。额外字段明确提示辅助记录不可靠，应以原任务和原始轨迹为依据。选出首位步骤后，其余步骤保持原 C 顺序。

不向模型提供旧 C 分数、角色优先级、缓存排名、训练示例或评测标签。A、B、判别的输出上限分别固定为 768、1,536、256 tokens，均使用既有授权的 `deepseek-flash`，temperature0、thinking disabled。辅助记录必须正常结束且非空；最终判别严格沿用原 P37 解析规则，没有另加结束状态限制。

## 结论边界
