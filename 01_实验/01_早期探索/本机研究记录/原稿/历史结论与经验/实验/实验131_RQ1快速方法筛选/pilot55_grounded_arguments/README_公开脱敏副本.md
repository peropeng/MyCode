# P55：可核验引用的支持／反驳论据与候选判断

本轮“神经／语义候选提议 A + 引用论据核验后判断 B”命中 4/32（12.500%），相同 B 流程作用于 C 候选时命中 6/32（18.750%）。44 份论据中有 29 份不满足固定格式约束，导致大量条件无法进入判断阶段。本固定流程淘汰，决定为 `STOP_FIXED_LITERAL_GROUNDED_ARGUMENTS`。没有修复响应、放宽约束、重试或移除无效样本。

## 两阶段流程

A 完全复用 P50 的神经／语义融合排序及 P51 已固定的前三候选。B 对每个候选提取一条支持论据和一条反驳论据，再用确定性规则核验引用，最后进行候选判断。B 单独使用的对照以 C 的前三候选为输入，执行相同流程。两路都保留完整原始任务和轨迹，不向模型透露候选分数、排名、条件名或评测标签。

共有 64 个条件位置，其中 1 个主条件继承了无效的 P 排序，不调用模型、保留为未命中；其余 63 个位置按完整请求哈希在本轮内共享 44 个论据请求。每个请求必须恰好覆盖三个候选，按固定 JSON 结构返回原始步骤索引、支持／反驳引用和简短说明。索引与引用必须同时为空，或满足整数类型及 12–160 字符的引用约束；说明必须非空且不超过 200 个 Unicode 字符。额外字段、重复键、类型、形状或覆盖错误均使该请求无效。

格式有效之后才执行引用核验。一个引用必须逐字、区分大小写地存在于指定步骤的某个原始 `content`、`action` 或 `thought` 字段中；不跨字段匹配，不归一化空白，也不进行模糊匹配。找不到原文或步骤越界时，仅按预定规则将该侧论据置空并记录原因。候选至少有一侧引用通过时保留说明，否则删除说明。引用存在只证明文本对应关系，不证明其解释真实或具有因果效力。

全部论据响应、64 个消费者映射、核验结果及阶段账本先封存，再从固定构造器生成判断请求。判断器使用原 P37 系统提示和完整原轨迹，额外接收核验后的不可信论据，不接收被拒绝的原始引用或无引用支撑的说明。沿用严格 `chosen_step` 解析器，把有效选择提升到各自原完整排序首位。格式无效的论据使相关条件直接记未命中并跳过判断；判断无效也不回退。

## 接口有效性与调用

44 个论据响应中，15 个格式有效，29 个格式无效。已保存解析状态的聚合诊断显示，28 个触发了论据侧类型、同时为空或引用长度等形状约束，1 个触发说明的非空／长度约束。这些是既有解析结果的汇总，没有重新生成、修复或重新分类。全部 44 个响应的结束原因为 `stop`，不能将其归因为 token 上限截断或运行时失败。

29 个无效论据请求影响 43 个条件位置；再加 1 个继承的 P 无效位置，共 44 个位置记为无效。其余 20 个位置通过本轮哈希共享执行 15 次判断，全部判断有效。两个新条件各有 22 条无效预测，分母均保留 32。

15 个格式有效的论据请求包含 45 个候选、90 侧引用。其中 83 侧通过逐字核验，7 侧因不属于指定原字段的连续子串而被置空；没有主动为空的引用，每个候选仍至少有一侧通过，因此 45 份说明全部保留。格式无效与引用被拒绝是不同计数，不能合并成一种失败。

新增调用为 44 次论据提取和 15 次判断，共 59 次；全部请求完成，传输失败、未结请求、资源暂停和正式运行失败均为 0。论据响应在本轮共享 19 次，判断响应共享 5 次，没有跨轮复用模型响应。新增拟合、编码器或神经模型前向、FIT 标签读取及文献基线运行均为 0。
