# P49：语义证据的两两交互

本轮固定主条件为“语义排名特征 A + 两两一致性特征 B”。主条件命中 22/32（68.750%），与普通加权及逐视图非线性对照相同，低于最好缓存基线的 23/32，也低于 P44 固定融合的 24/32。三个模型均正常收敛，按预先约定淘汰本轮组合。

## 方法与对照

直接复用 P48 的 64 条共同有效 FIT 样本、已合法读取并保存的 FIT 标签，以及局部不一致 L、全局纠正 G、持续影响 P 三类公开排序。本轮不重选样本，不重新读取源 FIT 标签，也不调用模型生成新特征。

每个步骤的基础特征为 `x=[-log(1+rL), -log(1+rG), -log(1+rP)]`，名次从 0 开始。预先固定三个映射，各拟合一次：

- 普通加权对照：三列 `x`。
- 逐视图非线性对照：六列 `[xL,xG,xP,xL²,xG²,xP²]`。
- 主条件：六列 `[xL,xG,xP,min(xL,xG),min(xL,xP),min(xG,xP)]`。

后两个模型参数量相同，用于区分跨视图交互与额外参数、独立非线性校准的影响。`min` 表示两项证据中较差的名次支持，但其系数仍是无约束学习的，不能把模型称为必然单调的硬一致性规则。

各列只用共同 FIT 集合计算 RMS：先在每条轨迹内对步骤取均值，再对 64 个不同任务组等权平均，开平方并设置 `1e-8` 下限；不居中。三个映射的前三列尺度严格相同，评测沿用这些冻结尺度。三个模型均无 C 偏置、无截距，使用 P48 的 CE 加 0.2 倍平均 pairwise softplus 和单位高斯正则目标，以及固定零初始化、float64 CPU 单线程 LBFGS。没有改正则、换求解器、重试、挑种子或按评测结果选权重。
