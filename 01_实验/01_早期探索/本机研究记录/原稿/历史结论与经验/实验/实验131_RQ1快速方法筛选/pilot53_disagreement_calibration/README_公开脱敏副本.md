# P53：按语义分歧状态进行条件校准

本轮“全局神经／语义融合 A + 分歧条件校准 B”命中 22/32（68.750%）。分歧组件单独使用和相同参数量的非线性对照也均为 22/32，低于 P50 全局融合的 23/32，以及两个已有对照的 24/32。三个新模型都正常收敛，固定门槛失败，淘汰本轮组合。

## 设计依据与模型

设计依据来自合法训练集的保存数据分析：FIT64 中，L/G/P 三路首选步骤全同的 38 条里共同答案命中 34 条；存在分歧的 26 条里，C、单独语义融合和 P50 联合融合分别命中 9、10、15 条。这些是训练描述，尤其融合系数在同一 FIT64 上拟合，不能把其训练表现称为新方法结果或独立增益。设计没有读取评测集逐案例 Gold 或正确性。

复用 P50 的四列公开特征 `v=[zC,xL,xG,xP]`：训练端 C 是既有组外神经预测，评测端 C 是原冻结全 FIT 神经预测；语义列为负对数名次。令 `u=0` 当且仅当 L/G/P 三路首选步骤完全相同，否则 `u=1`。这一规则只依赖公开排序，不依赖标签。

固定拟合三个模型：

- B-only 四参数：`u*v`。共识记录的分数全为零，明确按既有 C 精确平局规则排序。
- 非线性八参数对照：`[v,v²]`。
- 主条件八参数：`[v,u*v]`，共同学习四个全局系数和四个分歧调整系数。P50 的原四参数模型仅作缓存 A 对照，主条件不是冻结旧系数后只拟合一个残差。

所有模型使用同一批 64 条不同 FIT 任务及已合法保存的标签，各列只以 FIT 的等任务权重 RMS 缩放。共享四列直接复用 P50 的固定尺度，B 的四个条件列与主条件的后四列使用完全相同的尺度。不新读取源 FIT 标签，不重新分折、推理或拟合神经模型。

损失和求解器沿用既有固定设置：CE 加 0.2 倍平均 pairwise softplus 与单位高斯正则，零初始化、无截距、无 C 偏置、float64 CPU 单线程 LBFGS。三个头各拟合一次，没有重试、扫参数、换种子或验证选择。
