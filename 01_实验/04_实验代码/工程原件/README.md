# 可直接浏览的工程源码

此目录直接展开已公开代码包中的源码、小型配置、锁文件和核对回执，保持原字节。内部`src`、`tools`、Python包名等保留原布局，便于核对导入关系；中文业务分类由外层目录承担。历史英文Prompt和注释属于原实验版本，不作翻译后沿用旧成绩。

当前代码包中的全部Python源码均在下方可点开查看。3个体积较小的已有排序模型和回放特征也直接进入仓库，可按实验条件核对旧模型输出；大型机器清单、其他训练/恢复数据和历史环境配置继续放附件，完整原件未删。运行仍按[实验条件](../../02_%E5%AE%9E%E9%AA%8C%E6%9D%A1%E4%BB%B6/README.md)准备环境，不能执行历史授权或将旧配置当作新API设置。
