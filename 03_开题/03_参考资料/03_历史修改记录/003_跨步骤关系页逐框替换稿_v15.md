# 第27页

## 3.3 跨步骤关系建模

### 顶部导语

四类关系共享同一组步骤节点，但分别使用独立邻接矩阵计算邻居消息。这样可以避免把执行次序、角色相同和结构签名相同三种不同判据混入同一邻居集合。各类边均表示测试阶段可观察的步骤关联，不直接等同于因果依赖或错误传播路径。构图审计记录各关系类型的边数、节点覆盖率和孤立节点率[3][4][6]。

### 四个说明框

| 编号 | 标题 | 框内正文 |
|---:|---|---|
| 01 | **执行序列相邻关系** | 将步骤与其前一、后一执行步骤连接，使当前节点的表示包含相邻步骤信息；该关系不直接表示错误传播路径。 |
| 02 | **同匿名角色关系** | 对每个匿名角色，按执行次序连接相邻出现位置，使当前节点能够聚合同一角色在其他位置的步骤表示；该关系不直接表示责任归属。 |
| 03 | **同匿名完整结构签名关系** | 对内容、动作、思考字段的匿名结构及工具列表形态一致的步骤，连接最近的前后匹配项；构边不使用工具名、参数值或文本词汇。 |
| 04 | **同非空动作结构签名关系** | 仅对动作字段非空的步骤比较匿名动作结构签名，并连接最近的前后匹配项；签名一致仅表示结构相同，不表示作用于同一状态对象。 |

### 底部结论框

**方法定位：**四类关系共同形成一个多关系步骤图表示。跨步骤关系分支屏蔽检验关系分支是否提供排序增量；关系排序得分任务内置换检验得分与候选步骤的对应是否有效；节点置换图对照在保持各关系类型的节点数、边数与拓扑结构不变的条件下，检验原始邻接与节点初始特征的对应是否有效。现有协议评价四类关系的联合表示，不据此分别断言单个关系类型有效。

# 第28页

## 3.3 跨步骤关系建模

### 顶部导语

对每个候选步骤 i，模型按照四类关系分别确定邻居集合，并在每一类邻居集合内对上一轮的 23 维节点表示逐维求均值。每轮由此得到四个来源不同的 23 维邻域向量：执行序列相邻向量、同匿名角色向量、同匿名完整结构签名向量和同非空动作结构签名向量。第一轮使用直接邻居，第二轮使用已经包含一跳信息的邻居表示，从而形成二跳关系上下文。

### 按关系类型计算邻域向量

N_c(i) 表示步骤 i 在关系类型 c 下的邻居集合，z_j^(r-1) 表示邻居步骤 j 在上一轮的 23 维表示。对同一关系类型中的邻居表示逐维求均值，得到该关系对步骤 i 提供的 23 维邻域向量 m_(i,c)^(r)。图表示学习文献将这种由邻居传给当前节点的向量称为“消息”，这里不是自然语言消息。

```text
若 |N_c(i)| > 0：
    m_(i,c)^(r) = (1 / |N_c(i)|) × Σ z_j^(r-1)
                     j属于N_c(i)

若 |N_c(i)| = 0：
    m_(i,c)^(r) = 0_23
```

（5）

### 残差传播

每轮得到四个关系专属的 23 维邻域向量后，将它们与节点上一轮表示相加，形成下一轮仍为 23 维的节点状态。四个邻域向量虽然在状态更新时求和，但实现同时保留它们各自的来源，并在最终 215 维表示中按关系类型分别拼接，因此后续排序器能够对不同关系来源学习不同权重。

```text
z_i^(r) = z_i^(r-1) + sum{m_(i,c)^(r) | c属于C}
r属于{1, 2}
```

（6）

### 底部说明框

**空邻居的含义：**“空邻居”只表示步骤 i 在某一种关系下没有匹配步骤，并不表示该步骤在整张图中没有邻居。例如，步骤 i 通常具有执行序列相邻节点，但可能没有其他步骤与其具有相同的非空动作结构签名。由于空集合不能求均值，该关系的邻域向量定义为 23 维零向量 0_23，使它在残差求和中不产生贡献并保持表示维度固定；最终表示另设邻居存在位，用于区分“没有邻居”和“邻居均值恰为零”。

# 第29页

## 3.3 跨步骤关系建模

### 顶部导语

上述公式定义按关系类型进行的邻域均值聚合。对于每个步骤，每一轮分别计算四个 23 维关系邻域向量；第一轮编码直接相连步骤，第二轮编码经直接邻居传递的二跳关系上下文。两轮均值与残差更新采用固定规则，本身不含可学习参数；后续成对排序器仍需通过训练学习如何使用这些关系特征。

### 公式（5）

```text
若 |N_c(i)| > 0：
    m_(i,c)^(r) = (1 / |N_c(i)|) × Σ z_j^(r-1)
                     j属于N_c(i)

若 |N_c(i)| = 0：
    m_(i,c)^(r) = 0_23
```

（5）

### 符号解释

| 符号 | 页面解释 |
|---|---|
| C | **关系类型集合：**包含执行序列相邻、同匿名角色、同匿名完整结构签名和同非空动作结构签名四类关系。 |
| N_c(i) | **关系邻居集合：**步骤 i 在关系类型 c 下直接连接的步骤集合。 |
| r属于{1, 2} | **聚合轮次：**第一轮读取直接邻居，第二轮读取已包含一跳信息的邻居表示。 |
| z_j^(r-1) | **邻居表示：**邻居步骤 j 在上一轮的 23 维向量。 |
| m_(i,c)^(r) | **关系邻域向量：**对关系类型 c 下所有邻居的 23 维表示逐维求均值；没有邻居时取 0_23。 |
| z_i^(r) | **更新后表示：**步骤 i 的上一轮表示与四个关系邻域向量之和，维度仍为 23。 |

### 底部约束框

**表示构造：**初始节点表示为 23 维；第一轮保存 4×23=92 维关系邻域向量，第二轮再保存 4×23=92 维关系邻域向量；另加入四类关系的相对间隔均值与邻居存在位共 8 维，最终得到 23+92+92+8=215 维步骤表示。固定的是两轮邻域聚合规则，后续成对排序器的权重仍由训练数据学习。
