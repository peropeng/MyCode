### [1] L01 Which Agent Causes Task Failures and When? On Automated Failure Attribution of LLM Multi-Agent Systems

Shaokun Zhang; Ming Yin; Jieyu Zhang; Jiale Liu; Zhiguang Han; Jingyang Zhang; Beibin Li; Chi Wang; Huazheng Wang; Yiran Chen; Qingyun Wu. Which Agent Causes Task Failures and When? On Automated Failure Attribution of LLM Multi-Agent Systems. ICML 2025, PMLR 267:76583–76599.

发表状态：正式主会论文。

来源：[原论文](https://raw.githubusercontent.com/mlresearch/v267/main/assets/zhang25cq/zhang25cq.pdf)；[正式记录/项目页](https://proceedings.mlr.press/v267/zhang25cq.html)；[作者代码](https://github.com/mingyin1/Agents_Failure_Attribution)。

核心流程：All-at-Once读整段日志一次输出角色、步骤与理由；Binary Search在当前区间判断上/下半区递归到单步；Step-by-Step逐前缀审查。

参数与版本：官方推理输出上限1024；包装未显式固定temperature。AA一次调用，BS至多ceil(log2(T))。无答案配置必须删除官方默认提示中的ground_truth任务答案行；不得只隐藏mistake_step。

主张及条件：原基准最佳责任主体准确率53.5%、步骤14.2%；这是原论文后端和数据条件下的结果。AA和BS是同一论文两种方法，不能计两篇独立研究。

本文关系：RQ1主基线AA与BS；SBS与它们同论文、作者逐前缀核心完整，但尚无本机完整非零证据，仅为待核候选，当前合格备选仍缺。单步骤输出不能补造MRR；诊断接本文恢复器属于内部控制。
