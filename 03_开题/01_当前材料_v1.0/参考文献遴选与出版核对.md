# 参考文献遴选与出版核对

本轮仅修改术语、RQ2作用论证和实验呈现，30篇引用、编号、出版核定和分类均沿前版。未新增引用或重新检索。

本轮未变更30篇正式引用及首次出现次序，仅按学术术语、模块论证与数据用途修订正文。出版和分级结论沿已核定的论文与官方目录，本轮没有新增网络核验。

全文保留30篇实际引用的研究论文，研究现状集中讨论8项代表工作。本轮重核恢复核心论文及实际代码，保留当前30篇定向引用；恢复生成、检索与测试筛选按已有基础说明，拟研究差异按实际机制表述。

出版及CCF证据沿前轮核定目录；本轮逐句检查引用用途、原文证据与位置，未以数据卡、代码或本地文档补足论文篇数。
