## 当前编辑与恢复入口

当前开题在[01_当前材料_v1.0](03_开题/01_当前材料_v1.0/)维护。公开稿和本地私人原件归在同一开题目录，MD、Word、PPT与登记表用途不同，不自动互相覆盖；其余版本按原版本保存。

换机先克隆MyCode，再按[实验条件与恢复](01_实验/02_实验条件/README.md)执行：

```powershell
git clone https://github.com/peropeng/MyCode.git
cd MyCode
git config core.longpaths true
python 01_实验/02_实验条件/restore.py --code
```

恢复只校验、下载和物化，不启动训练或模型请求。受保护原件需研究者单独保存的本机或离线密钥，旧私库不再用于日常同步和恢复。完整材料、旧路径与现行位置见[文件位置与同步范围](文件位置与同步范围.md)。
