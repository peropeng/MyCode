## 换机从哪里开始

```powershell
git clone https://github.com/peropeng/MyCode.git
cd MyCode
git config core.longpaths true
python 03_实验条件/restore.py --code
```

此命令只下载代码原件和已有回放模型，不训练、不发模型请求。之后按[环境说明](03_实验条件/README.md)安装锁定依赖。完整实验原件使用发布页加密附件，密钥由研究者在本机及单独的离线备份中保存，不再从旧私有仓库获取；导师查阅公开正文不需要密钥，访问原始完整档案需研究者提供解密凭据。受保护附件包含数据、请求、日志、候选、Checkpoint与独立验收原件，防止密钥、个人配置或评价答案被直接公开。

目录和新维护代码注释使用中文。[工程源码](05_实验代码/工程原件/README.md)和[有价值历史实现](05_实验代码/历史实现/README.md)可直接打开。历史冻结代码含原作者或历史英文提示词，展开浏览时保持原字节，并保留完整附件；翻译或修改提示词须形成新实验条件，不能继续当作旧结果的代码版本。

全部此前开题材料完整保留，当前版本只作为默认浏览入口；[可公开历版材料](07_开题材料/README.md)已按原版本分组展开。含学号、签名或录音的原件不明文公开。未确定归属和原件缺口见[保留与续跑说明](06_实验记录/实验保留与续跑.md)。旧私有仓库已退出日常同步和恢复流程；独有本机材料、原件来源记录与旧Git历史均保留；同字节副本已合并到规范位置。
