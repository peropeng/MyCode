# 持续增加实验与材料

新实验按研究问题放入中文目录，记录输入来源和固定版本、代码版本、Prompt版本、全部配置、种子、命令、环境锁、预算与输出位置。RQ2未核定内容继续标为探索条件，不提前归入最终方法。新维护代码用英文文件名、中文注释与中文提示词；历史原件不覆盖。

运行时在忽略目录保存完整请求发送状态、响应、工具调用、补丁候选、中间源码、测试反馈、模型/Checkpoint、游标和费用记录。模型请求未知时先核对原请求，不重发。最终选定状态和独立验收分开，评价答案不送回生成器。

流程停止后，用现有加密凭据创建新附件：

```powershell
python 06_实验记录/create_archive.py --input 工作区/恢复/实验输出/新实验 --output 工作区/恢复/发布附件/new-experiment.tar.gz.enc --key-file 工作区/私有配置/mycode-recovery-key.json
```

该工具会检查封存期间输入没有变化，生成完整文件清单，并拒绝覆盖已有附件。它不启动训练、模型调用或测试。源码、运行配置和命令应随实验目录一起输入，不能只打包指标文件。生成的机器清单记录校验数据，面向人的说明写研究问题、设置、原计数、结果与影响。

使用新的发布版本上传附件，更新`恢复清单.json`中的实际URL、原件前缀和恢复目的地；不得覆盖旧版本资源来伪装同一实验。密钥只保存在研究者本机与受控备份，不放公开仓库。先验证解密和恢复，再发布引用新版本的说明。恢复工具的合成验证命令：

```powershell
python -m unittest discover -s 03_实验条件/验证 -v
```

新增数据条目需要官方来源URL、实际下载链接、固定版本、许可和本研究中的用途。上游版本变化不自动替换旧实验输入。新开题稿作为当前入口更新，所有旧稿、图表、修订记录和原文件布局继续归档，敏感原件使用受保护附件。
