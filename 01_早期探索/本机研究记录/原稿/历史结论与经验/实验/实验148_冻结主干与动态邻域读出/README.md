# 实验148：冻结主干与动态邻域读出

本实验执行批准的 `approved_decision.json`。数据沿用实验138的731条轨迹、716个任务组和固定120题，三个种子、五个外折及原始步骤坐标均保留。实验146提供已核验的30个三折内层基座缓存与30个四折外层缓存，148只训练新增的残差读出模块。

每个候选步骤使用自身的128维归一化内容作为 query。邻域由原始四类邻接的有效 source 并集构成，按原始序号排序、去重并排除自己，不截断邻域。旧基座的图、输入、权重与 scaler 保持冻结。新增模块以 query 与 source 的联合投影生成注意力，再将 source 内容的加权聚合交给残差读出，总计20,609个参数。

四臂共用每个 seed/outer 的完整初始化和训练配置：`AB_DYNAMIC` 为主臂；`AB_STATIC` 将标量投影放在 LeakyReLU 前；`AB_VALUE_SWAP` 保持 query 和 key，按预先冻结的接收者局部轮换改变 value 槽位；`SF_DYNAMIC` 使用冻结的 matched StepFinder 基座。最后一层初始化为零，epoch 0 是有效选择候选。选择在三折 fit 与一折 validation 上进行，按任务组等权 Top1、MRR、最早 epoch 决定；从同一初始化在四折 fit 上重训所选 epoch，随后预测外折。

所有7,366个节点都有非空邻域，731条轨迹均存在实际 value 置换；6,604个接收节点涉及数值变化。23,532个名义轮换槽位中，23,492个归一化向量实际改变。输入变化与聚合变化分别记录：普通外折前向同时保存同一 alpha 下自然 value 与冻结轮换 value 的 context 差异，不生成额外预测。

四臂的三个种子输出与 ensemble 共11,696条记录全部封存后才开始统一外折评分。主比较保持固定120题的八项家族；机制比较在全716个任务组上对 STATIC 与 VALUE_SWAP 使用两项校正。全量轨迹、域分层和各 seed 的恢复、退化及共同正确/错误结果均保存，不选择最佳 seed 或替换主臂。

这是已多次使用的历史数据上的 OOF 开发比较。动态注意力或聚合变化本身不能证明证据正确、语义继承或因果恢复。实验136/137的688条独立来源旧输出作为保留资产保护，不代表新 AF 模型在其他来源上的泛化成功。

执行入口为 `freeze_neighbors.py`、`preflight.py`、`runner.py run`。其中 `runner.py` 连续完成训练、输出封存、`evaluate_stage.py` 评分和 `finalize_stage.py` 收尾。已冻结协议中的文件须保持哈希不变；执行状态保存在 `execution_state.json`，最终结果见 `main_decision_packet.json`、`comparison.json` 和 `final_execution_audit.json`。

本阶段不调用 API、encoder 或下载，不取得新 Gold，费用为0元。连续请求账本、旧模型和旧实验产物保持只读。独立 sparse worktree 与原始基座、缓存的绝对路径引用一起保留，供主线程验收。

## 本次结果

执行与收尾审计 PASS，全部11,696条输出已封存。四臂固定120题分别为81、80、81、75；原AB为84、B为86、matched StepFinder为75。主臂全731条为579/731，原AB为583/731；全716组等权 Top1 为80.7263%，原AB为81.2849%。相对原AB恢复3例、退化7例；相对原B恢复37例、退化31例。STATIC 与 VALUE_SWAP 的全组等权 Top1 均为80.8659%，两项机制比较的 Holm 校正 p 均为1，未确立所测试的增量机制收益。

实际执行60次选择优化和35次非零 refit，另有25次 epoch 0 identity refit；合计23,481步。新增基座优化、重建、前向、API、encoder、下载与新 Gold 均为0。原138/146/147资产哈希核验通过，D盘剩余约2.07GB。代码、协议、缓存引用、完整输出和失败结果保留于当前独立 worktree，尚未提交或合入。下一科学决策由主线程负责。
