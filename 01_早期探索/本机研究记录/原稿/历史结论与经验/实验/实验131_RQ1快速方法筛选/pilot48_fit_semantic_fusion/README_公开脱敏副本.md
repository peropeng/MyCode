# P48：FIT 学习的语义证据融合

本轮检验“局部与全局证据融合 A + 持续影响证据 B”。固定 32 条开发评测中，A 命中 23 条，A+B 命中 22 条，低于已有固定融合的 24 条，也未超过最好缓存文献基线的 23 条。两个模型都正常收敛，按预先约定淘汰本轮组合，不扩大运行。

## 方法与监督范围

从原有合法 FIT 集合按事先固定的公开身份哈希规则选择 64 个不同任务组，每组一条记录；排除 pilot 任务组及相同任务文本，不用标签决定入选者。分别调用三个冻结的自有提示，得到局部不一致 L、全局纠正 G、持续影响 P 的完整步骤排序。192 次调用全部完成且格式有效，因此共同训练集合恰为全部 64 条，均非单步骤轨迹。

先封存公开排序和共同训练集合，再按记录白名单一次读取这 64 条 FIT 标签。A 使用 L、G 的负对数名次特征，A+B 使用 L、G、P 三列；两个模型共享样本、损失和优化设置。分数不含 C 偏置、截距或标准化。损失为逐任务 CE 加 0.2 倍非 Gold 步骤平均 pairwise softplus，再加单位高斯正则，并除以共同样本数。使用固定、零初始化、float64 的 LBFGS，各拟合一次，不重试，不选种子或扫描权重。

固定 32 条评测只复用原有公开 L/G/P 排序。P47 中一条 P 输出无效，所有依赖该输出的条件仍计为未命中，分母始终为 32；不补调用、不替换样本。模型参数与全部 256 份条件／任务预测封存后，才一次读取这 32 条评测标签。C 只处理精确分数平局。
