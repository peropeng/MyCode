## 方法和实际结果

A从完整原始轨迹提取最多3个按可信程度排序的责任候选，每个候选给出原始步骤、该步骤的引用以及同一步或后续步骤的引用证据。解析器核对字段、索引和引用在指定原文中的精确存在性。A单独按候选顺序排序，其余步骤按C缓存顺序排列。

B是P38冻结的全局纠错影响排序。A+B把通过核对的非空见证加入完整轨迹，再执行相同B准则下的全步骤排名；候选见证不限制B可选步骤。A合法为空时，按事先固定规则复用提示哈希完全一致的P38 B缓存；A无效时，A和A+B均计未命中，并跳过新B调用。引用存在不等于所指控的错误或因果关系正确。

## 结论边界和未运行后续

当前见证接口产生了12例无效输出，且组合在完整32例上的结果低于A和B，不支持该固定流程的效用。原文核对只是接口约束，不能替代事实或因果验证。证据提取与判断模型的组合已有相关工作；本实验不主张它是新的通用算法。这批32例已反复用于开发，不能称为独立确认。
