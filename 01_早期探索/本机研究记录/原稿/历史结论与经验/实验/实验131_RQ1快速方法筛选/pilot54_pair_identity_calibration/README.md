# P54：按语义排序的成对共识进行条件校准

本轮“全局神经／语义融合 A + 成对共识校准 B”命中 20/32（62.500%）。B 单独使用为 20/32，相同参数量的多项式对照为 22/32，均未超过已有最佳自有对照的 24/32。三个新模型正常收敛；按事前约定淘汰本轮组合，并结束一致性分组、门控和多项式校准这条分支。

## 设计与训练

本轮设计依据是合法 FIT64 保存数据中的训练描述，未读取评测集逐案例标签。L/G/P 是三路已有语义排序。其首选步骤仅有两路相同时，定义互斥的 LG-only、LP-only、GP-only 三个公开分组；全部相同或全部不同时，三个指示量都为零。训练中三组分别只有 3、11、11 条，另有 38 条全部相同和 1 条全部不同，这种样本规模限制了条件系数的可信度。

沿用 P50 的四列特征 `v=[zC,xL,xG,xP]`：C 在训练端为已有组外神经预测，在评测端为冻结的全 FIT 神经预测；语义列为负对数名次。固定拟合三个头：

- B-only 十二参数：三个分组各自的 `gate*v`。
- 同参数量十六参数对照：`[v,v²,v³,v⁴]`。
- 主条件十六参数：`[v,gate_LG*v,gate_LP*v,gate_GP*v]`，共同学习四个全局系数和十二个分组调整系数。

原 P50 四参数模型仅作为缓存 A 对照。新主条件共同拟合全局与调整系数；训练使用同一批 64 条合法缓存 FIT 标签，未重新读取源标签、运行编码器或拟合神经模型。各列使用 FIT 等任务权重 RMS 缩放，共享四列沿用 P50 尺度，B 与主条件的十二个调整列尺度相同。

损失沿用 CE 加 0.2 倍平均 pairwise softplus 与单位高斯正则，零初始化、无截距、无 C 偏置，使用 float64 CPU 单线程 LBFGS。每个头只拟合一次，无重试、参数扫描或验证集选择。
