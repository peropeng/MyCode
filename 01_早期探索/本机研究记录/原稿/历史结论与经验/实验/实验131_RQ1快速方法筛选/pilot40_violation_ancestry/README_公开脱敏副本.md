## 方法与比较

本轮A由模型在完整原始轨迹中标记局部违规；B由同一次模型响应给出各步骤的直接语义依赖。B单独按不同下游节点数排序。A+B把每个违规点的一单位证据沿依赖图回传到最近的已标记祖先：祖先集合去重、等分、使用精确分数，保留原C排名处理并列。时间链对照保留相同标记与算法，把依赖替换为相邻时间步。

这不是此前的角色分类A；本轮没有角色筛选、训练记忆、新模型训练或FIT/验证标签读取。一次图推理被四个确定性评分条件共用，不是四次独立模型推理。

## 结论边界与未运行后续

语义图组合与时间链对照同分，不支持本轮图结构带来预测增益。模型生成依赖及违规标记是待验证的判断，解析成功不等于事实正确或因果关系成立。这32例经过多轮开发，不能提供独立测试证据。

[GraphTracer](https://arxiv.org/html/2510.10581v1)已有依赖回溯，[DCFA](https://arxiv.org/html/2609.04749v1)已有全局图和局部反事实启发，[EDGE](https://arxiv.org/html/2609.01360v1)已有依赖图引导的多错误检测。因此不能把依赖图或回溯本身宣称为新贡献；本轮仅检验一个固定的证据聚合设计。来源边界记录随附。

另存P41末端违规见证评分的候选设计与纯逻辑检查，但没有真实运行：它冻结复用同一批8个无效图，理论最多24/32，已低于25/32门槛。其登记晚于P40物理结果产生、早于根线程收到结果；时间纠正记录明确保留，不能称在P40结果产生之前注册。P41不计新增完成实验、模型调用或准确率结果。
