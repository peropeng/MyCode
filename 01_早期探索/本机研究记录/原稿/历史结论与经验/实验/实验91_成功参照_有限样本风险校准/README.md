# Exp91：成功参照有限样本任务组风险校准

## 结论先说

本实验得到的是一个真实、同预算、无泄漏的正向结果，但还不是 GO：

```text
POSITIVE_NOT_YET_GO
```

原因不是方法没有提升，而是相对预注册的全局公平基线，前两个 seed 的任务组 paired bootstrap 95% CI 下界仍跨 0。三次 seed 的提升方向全部为正，第三个 seed 的 CI 下界已经大于 0，因此不能把本实验写成 NO-GO，也不能把它升级为正式 GO。

## 本轮只验证什么

Exp89 的 comparability gate 在三个 seed 都覆盖 100%，没有改变 Exp86 的 paired-reference。Exp91 不增加特征、模型、候选、任务、API 或预算，只把报警阈值从经验的“行级 FPR 不超过 10%”改为：

1. 每个 outer fold 内，校准集只使用包含至少一条 success run 的任务组；
2. 对每个候选报警阈值，记录该任务组中是否有任一 success run 报警；
3. 用单侧 95% Clopper–Pearson 上界 `Beta^-1(0.95; k+1, n-k)` 估计 group-any 风险；
4. 从校准成功行的最大分数及其 `nextafter(+∞)` 中，选择最低且上界不超过 0.10 的阈值；若没有，选择明确的 NO_ALARM。

所有阈值在 outer test 之前冻结。outer test 只用于最终打分，不参与阈值或方法选择。

## 主要结果

全局公平基线按预注册规则确定为 `clean_no_reference_empirical`：它在三个 seed 的 row-FPR 都不超过 10%，且三 seed 平均召回高于其他全局合格候选。`paired_reference_empirical` 因 seed 20260825 的 row-FPR 为 13.266% 不具备风险资格，但仍完整报告。

| seed | 全局基线召回 / row-FPR | paired CP 召回 / row-FPR | paired CP group-any FPR | 相对基线绝对提升 | 相对提升 | 任务组 CI 95% | better/worse/tie |
|---|---:|---:|---:|---:|---:|---:|---:|
| 20260823 | 3.738% / 2.928% | 4.673% / 0.732% | 2.182% | +2.642 个百分点 | +25.0% | [-1.626, 7.520] 个百分点 | 4 / 3 / 75 |
| 20260824 | 1.869% / 3.294% | 2.804% / 0.640% | 1.455% | +1.829 个百分点 | +50.0% | [-1.423, 5.894] 个百分点 | 3 / 2 / 77 |
| 20260825 | 0.935% / 1.921% | 7.477% / 1.098% | 2.545% | +7.317 个百分点 | +700.0% | [2.033, 13.415] 个百分点 | 7 / 1 / 74 |

换成直白的话：

- 三个 seed 中，paired CP 都比公平基线抓到更多 failure；
- 同时，paired CP 的 success 行误报率只有 0.64%～1.10%，任务组 any-alarm 误报率只有 1.45%～2.55%；
- 但前两个 seed 的数据量和有效差异仍不足以排除“这次提升是抽样波动”，所以不能宣称稳定 GO。

## CP 校准证据

每个 fold 的校准成功任务组数约为 39～49。paired CP 的 `k/n` 和上界如下：

| seed | 每 fold 的校准 `n` | 每 fold 的报警组 `k` | 每 fold 的 CP 上界 |
|---|---|---|---|
| 20260823 | 44、39、43、45、49 | 0、0、0、0、1 | 0.0658、0.0739、0.0673、0.0644、0.0932 |
| 20260824 | 41、42、42、46、45 | 0、0、0、1、0 | 0.0705、0.0688、0.0688、0.0990、0.0644 |
| 20260825 | 47、40、42、46、45 | 1、0、0、1、0 | 0.0970、0.0722、0.0688、0.0990、0.0644 |

因此风险阈值不是用测试集调出来的；每个 fold 的校准上界都不超过 0.10。`reference_deletion_risk_bound` 与 `clean_no_reference_risk_bound` 的分数、阈值、预测和指标严格相同。

## 机制对照

跨任务参照的 CP 结果（召回 / row-FPR / group-any FPR）为：

| seed | cross-group CP |
|---|---:|
| 20260823 | 0.935% / 0.092% / 0.364% |
| 20260824 | 7.477% / 4.483% / 8.000% |
| 20260825 | 2.804% / 0.549% / 1.818% |

跨任务对照在部分 seed 也有提升，说明本次结果证明了“有限样本风险校准有效地压低误报并保留部分召回”，但还没有完全证明提升只能来自同任务成功参照。后续最小动作应优先处理这个机制归因问题，而不是添加第三模块。

## 为什么不是 GO，也绝不应写成 NO-GO

唯一未通过的 GO 门是：

```text
task_group_ci_lower_gt_0_all_three_seeds = false
```

20260823 和 20260824 的 CI 下界分别为 -1.626 和 -1.423 个百分点；20260825 已为 +2.033 个百分点。这个结果说明证据还不够强，不说明方向失败。

本实验没有触发任何绝对 STOP 条件：

- 不是实现错误：9 项单测、编译、数据封存和删除等价审计通过；
- 不是泄漏：没有使用测试结果或禁用字段；
- 不是预算不公平：模型、前缀、任务折分和 API 预算相同；
- 不是零提升：三 seed 的 paired CP 相对全局基线绝对差均为正；
- 不是方向级 NO-GO：本轮只失败或通过一个有限样本风险控制机制，不能计作成功参照方向的三次实质方法失败。
