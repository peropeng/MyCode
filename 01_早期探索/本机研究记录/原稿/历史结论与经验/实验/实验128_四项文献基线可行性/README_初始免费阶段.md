## 固定数据和信息边界

AF 从既有 731 条／716 组／7,366 步开发分区中，按预设种子与匿名 ID 的 SHA256 顺序取前六个不同任务组，索引为 **721、693、205、40、121、639**。选择不使用标签或模型分数。`samples/af_manifest.json` 保存规则、输入哈希和来源 ID；`af_labels.evaluation_only.jsonl` 仅供独立评价器读取。历史 180 条／168 组分区本轮不用，也不称全新独立确认集。

恢复继续使用已有 getmoto__moto-5134、5286、6352 三个中间开发状态。SWE-Gym 环境与 OpenHands 成功轨迹按任务 ID 配对，既有 11 条筛得这三项；每源任务只取一个状态，候选数固定 4／2／1。公开来源仍为三项，实验数据仍为诊断与恢复两组，未新造数据集。

所有诊断输入均排除任务正确答案、责任标签、参考补丁及失败截断点之后的修复记录。AF 保留相同候选步骤；生成式提示可见公开任务和原角色名，StepFinder 保持其已训练的 content/action/thought JSON 与匿名角色投影。恢复生成式输入包含完整编号前缀、全部可见测试状态及按测试名排序的首个非通过 traceback；其余重复 traceback 保存在完整样本中，不重复发送。StepFinder 未额外编码 observation、task 或 failure_feedback，这一表示差异不隐藏为完全相同模型输入。

协议汇总见 `protocol.json`。该汇总文件写于首批 StepFinder 诊断之后；样本规则和模型选择此前已在执行指令及样本文件中固定，但**没有声称整份协议已在首跑前提交预注册**。

## 耗时、费用和失败原因

AF 当前平均诊断 0.102560 秒，使用既有真实嵌入缓存；本次编码为 0，不能据此声称完整首次诊断更快。恢复诊断共 18.73 秒（首条含 Qwen 首次加载），有效恢复执行共 245.88 秒，按任务合计 **264.61 秒**。编码、模型推断、缓存读取、启动核验分别保存在预测和 `*.run.json`，不是将缓存命中时间冒充冷启动成本。

| 情况 | 性质 | 已采取的处理 | 是否进入真实效果分母 |
|---|---|---|---|
| 三个生成式方法缺本轮 API 金额 | 资源／授权阻塞 | 现有键仅核对存在性；常见本地服务/缓存检查未发现可用生成器；请求门返回 blocked | 否；指标 null |
| SDBL 只有 README，角色权限/完整提示未公开 | 复现资料缺口 | 按论文两阶段重建；Overstep 只据明确权限，未知权限不凭名字补造；保留 Loop 与全日志定位 | 无真实运行，尚无效果分母 |
| StepFinder 首轮单样本 kernel 分数有微差 | 数值重现检查失败 | 保留首轮；恢复原批次成员和计算形状，最终差为 0，权重未变 | 最终六条只计一次 |
| 恢复首轮相对 guard 日志路径错误 | 基础设施失败 | 保留 v1；改绝对路径，原预测不变，新目录 v2 真实重跑 | v1 排除；v2 三条纳入 |
| StepFinder 有效运行的前三次失败候选 | 真实恢复测试失败 | 5134 前两项、5286 第一项失败均保留，然后按预算继续 | 保留在成本与尝试表 |

AF 数值核验初轮实际 6 条前向；最终为 6 次原 batch 前向、82 条不同轨迹进入计算，仅六条进入评价，不声称伙伴“未推理”。恢复另对 50 个内容文本和一个角色文本真实编码。没有重新训练或新增大型模型下载。

基础设施失败轮已记录的额外时间至少 58.55 秒；一个被中断任务缺完整计时，只报告下界，未捏造总数。明细为 `recovery/infrastructure_overhead.json`。所有实际生成 API 请求、token、费用均为零。为后续准备的 DeepSeek 官方价格与共同费用账本见 `authorization.pending.json`、`model_client.py`；当前 `approved=false`、金额 null，不会发送生成请求。费用预留使用官方峰值费率；跨进程排他锁覆盖余额重读、预留、HTTP 与结算，失败或不明账单保留预留额，不自动重试。

固定九条样本的三项生成式策略最多规划 61 个请求，保守预留规划约 $0.7766（`results/cost_plan_v2.json`）。这只是按输入字节和输出上限计算的计划，**不是实际账单，也不是已获授权额度**；运行时逐请求继续检查共同上限。

待授权运行计划统一使用已配置资源对应的 DeepSeek Flash、关闭 thinking、temperature=0；这将是原策略在共同生成模型上的适配，不是复现原论文 GPT-4o 数值。All-at-Once/SDBL 每请求输出上限 2048，Binary Search 128；二分格式不合法时记失败，不采用原仓库的随机选半区后备。
