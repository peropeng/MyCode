旧Exp112C模型只接收23维匿名结构，使用四关系固定均值聚合和线性责任排序；合法可见的content/action/thought语义未进入表示。Exp129固定120组中，旧方法的93次错误有48次角色正确但步骤错误、45次角色也错；9–16步轨迹只命中3/42。这些既有开发观察提示，既要补充语义，也要区分同角色的不同步骤，不能将上述观察当作新验证结果。

v2/v3的Semantic Relational Residual Ranker保留原23维结构，加入同一Exp124缓存的128维内容语义及32维匿名角色表示。数据字段投影与缓存逐项哈希一致。四类关系沿用时间相邻、同角色、同完整结构、同非空动作结构；每类关系将发送节点及与接收节点的差异变换为消息，用可学习边门控和节点条件关系权重融合，再以残差和LayerNorm保留自身信息。两个消息层之后，将当前状态、初始状态、轨迹均值及相对均值差异送入任务内排序头。该代码独立实现，没有调用StepFinder模型或推断。

v2中的`no_relations`是内部机制消融：保留语义、结构、投影和排序头，删除两个关系模块。它不代表文献基线。两种模型均报告三种子五折，不能从中挑最高种子。

v2/v3的训练沿用Exp124/Exp96的716任务组划分。每一外折以首个非留出折作内部验证，其余三折训练，按内部验证组等权严格步骤Top1选择最早最佳轮次，然后从同随机初始化在全部外折训练组上重训。标准化统计仅在相应训练集合拟合；外折留出和固定120组不参与轮次或超参选择。训练损失为组内轨迹平均后的任务内交叉熵与0.2倍成对softplus，再在一批完整任务组间平均。
