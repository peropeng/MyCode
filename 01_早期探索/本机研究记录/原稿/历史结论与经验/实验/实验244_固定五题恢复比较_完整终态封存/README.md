# 固定五题恢复比较的完整结果与检查点

当前三个方法均完成五题：本文2题成功，Agentless 3题成功，EnAgent 2题成功；完整运行恢复率分别为40%、60%、40%。原30分钟固定预算结果仍为40%、60%、0%，没有因续跑而覆盖。本文尚未超过Agentless。

`REPORT.md`保存同一份学术汇报的最终副本，`SEAL.json`绑定结果、报告、费用及旧预算记录；`evidence/`保存已验收终态、独立探针结果、进程停止记录、当前完整检查点、RQ1使用审计与连续账本快照；`source/`保存本轮实际执行接口源码和冻结协议，原运行目录与绝对路径仍保留。

`ARCHIVES.json`及各`*_FILES.json`记录本地压缩包的SHA256和逐文件清单。`archives/`包含全部三条续跑轨迹的原子检查点与内容寻址文件、原始续跑谱系和不可变克隆，以及三个方法五题的完整请求、响应、usage与公共执行记录。另一个压缩包保存本文五题请求和关系输出，以及实际接入的15个既有RQ1训练检查点；原始本文终态与批准记录已按此前审计的SHA复制。压缩包为本地恢复资产，已由本目录`.gitignore`排除；跨机器保存或传输时须连同该目录单独复制，Git提交本身不包含压缩包。原始工作区没有删除。

已结束的方法不会从终态继续增加样本。未来执行沿用保存的模型与工具边界：已结算响应只回放，明确未POST的请求才发送，费用未知/inflight状态必须先核对，不自动重发。检查点保存消息、阶段、内部步数、候选、投票、工具与撤销状态、种子游标、原始时钟和累计消耗。恢复入口与协议仍引用原绝对路径；迁移时按压缩包内的仓库相对路径恢复并重新核对清单，不能仅改路径即假定新机器环境等价。
