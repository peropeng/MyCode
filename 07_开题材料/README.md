公开副本保留研究作者和指导教师署名。当前报告与PPT的文本、包内元数据及嵌入图片已核对，未发现学号、手机号、邮箱或签名图片。登记表包含学籍类信息及签名栏，不纳入公开目录；教师评议录音、逐字转写及个人制作配置也不随本目录发布。原件均未删除。
