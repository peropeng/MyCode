# 本轮开题文稿重构要求

本轮依据导师录音意见、本对话对导师原意的纠正，以及学校开题通知重构。题目采用《智能体运行故障的根因排序与恢复方法》。上一版文稿和实验记录作为事实来源，重构论证与文字；图表沿用已确认的结构，按当前内容调整。

## 一、开题需要证明的内容

文稿要让读者判断：选题是否有价值，研究问题是否确实存在，已有方法具体缺少什么，拟采用的方法为什么适合解决问题，以及如何通过实验检验。计划工作与已有结果分别陈述。

学校要求的内容全部保留：选题价值与意义；相关国内外研究现状及趋势；研究目标、思路、方法与技术路线；研究重难点、拟创新点及不足；主要内容与论文初步框架；进度安排。

## 二、第一章：围绕已定题目建立研究依据

第一章直接从智能体执行轨迹及其失败问题开始，不再介绍LLM、Agent的基础概念和发展背景。

研究现状总节为“1.2 国内外研究现状”，内部按根因诊断与排序、诊断支持的软件恢复分成1.2.1和1.2.2。以已定题目和研究内容定向筛选少量直接相关的工作，取消逐篇列点；在连贯论证中保留必要的方法名、作者与年份。MAST等无直接论证作用的文献移出主文与正式引用。

1. 先根据已定题目和两项研究内容，查找对应方向论文，再直接说明相关工作的不足，支撑两个研究问题。
2. 每篇重点论文讲清研究对象、具体做法及与本课题有关的限制。段落之间用技术关系衔接，文献分析要服务于本课题的必要性。
3. 不把“已有方法没有上下文、没有交互、没有验证”等笼统判断当成研究空白。已有方法确实包含的机制必须如实说明。
4. 明确运行故障、工作流、执行轨迹、步骤、根因候选、排序和恢复的含义。直接说明连续执行、错误传播与分散反馈为什么需要历史步骤分析，以及排序怎样组织检查次序并支持恢复；不预设质疑或通过个别示例限定“哪些地方才有必要”。
5. 删除突兀引入的“源码缺陷定位”论述及为此增加的概念比较。围绕智能体的历史行为分析和失败后的继续求解展开。
6. 第一章交代背景为何引出这两类相关工作、排序如何衔接恢复，以及具体文献不足为何推出两个RQ。1.3之前归结两方面不足及其影响，避免以泛泛的“提供基础、进一步研究”收尾。

## 三、第三章：按模块解释方法

1. 先给出总体过程及两项研究的接口，再分别解释排序与恢复模块。
2. 各模块写清输入、操作、输出、作用和后续去向；说明这些模块为什么能组成完整方法。
3. 名称反映实际运算。消息传递、自注意力、位置监督等既有机制与本课题的具体设计分别交代。
4. 专业词汇和符号首次出现时就地定义。正文减少公式，必要公式只使用已经定义的符号；详细计算放入独立技术讲解。
5. 根因候选的排序输出、训练用的标注位置及恢复时实际选入的历史编辑分别说明，保持对象一致。
6. 独立技术讲解使用同一个贯穿例子，说明每个模块实际读入什么、改变什么和输出什么。示例与真实实验结果明确区分。

## 四、第五章：解释数据与实验的理由

1. 三个数据来源分别说明内容、选用理由、承担的验证任务及相互关系。
2. 区分原始发布数量、本地候选数量、训练验证数量、独立评价数量和计划运行次数，写清统计单位及来源。
3. 不使用“几折”组织本轮开题叙述，也不把它改名后继续保留同一套轮转安排。本轮采用有明确职责的固定训练、验证与评价划分。
4. 训练用于学习参数，验证用于选择配置，评价用于检验固定方法。相同原问题的派生轨迹不能跨集合。
5. 解释旧稿A/B/C的真实含义和当前实施证据。本轮不再将无独立研究目的的多组随机划分列为主要实验内容；旧记录保留在审核说明。
6. 整数计划样本量要说明预算与覆盖考虑，非整数式的精确数量要说明来自实际清单。不得为使数字整齐而编造样本量。
7. 每项比较和消融对应一个明确的验证目的；工作量由样本、方法、配置和重复次数计算，不以运行次数代替实验论证。

## 五、表达与后续修改控制

正文控制在10,000字以内，突出开题内容。完整参考文献直接附于文稿末尾，不计入正文字数，不能仅用外部参考文献表链接代替。保留必要定义、技术理由与证据，删去重复解释、无关领域比较和评价个人能力的内容。

正文小节标题采用正式学术表述，直接概括研究对象、方法或实验内容。1.1使用“研究背景与意义”；避免讲解式、提问式标题和仅按模块数量命名的小节。

图表沿用原有布局和字段：保留三张方法图，删除Moto案例图；图中文字与当前目标、模块和术语同步。保留原来的七张表，两张基线表沿用“方法—正式发表时间—发表载体—核心机制或过程”，共同指标用表外文字说明。

采用`manuscript-writing-review`五轮审核和`anti-defensive-writing`复核，另建本目录的术语与论证规则。后续新增术语、改动模块、替换数字或调整引用，都必须核对定义、上下文、事实来源及对其他章节的影响。

正式引用保持30—40篇论文：主体为2024年以来正式CCF B类及以上，经典理论不限年份，预印本少于10%。研究现状减少罗列不减少全文必要引用；数据卡、版本发布、代码和本地清单进入溯源，不占论文名额。

文稿按自然段分行，并另做逐段溯源分析。每段记录原文、位置、论断性质及直接来源；区分文献定义和事实、比较分析、本文设计、本地数量与计划。核心排序动机是失败原因不能由终态结果直接确定、证据分散于不同智能体与步骤；专业中文表达核对相关高质量中文原文，保持导师要求与学术专业性。

## 六、本轮交付

- 重构后的完整开题文稿。
- 与正文模块一致的第三章技术讲解。
- 可继续使用的术语与表达审核规则，以及本轮Skill审核、事实核对和方案调整记录。

## 题目一致与引用位置（2026年10月29日补充）

1.1只围绕已定题目解释执行轨迹、步骤、运行故障、根因排序与恢复的关系。删除无关的通用软件智能体工作流背景，不使用突兀的“失败归因”叙述；具体论文、作者、方法及其特定错误定义在1.2介绍。执行轨迹先交代完整过程，步骤先交代具体决策或交互活动，编号与来源边界放到数据适配。专业中文的组织方式实际查读高质量中文论文，英文论文支撑专业对象和做法，不能将中文来源没有给出的定义强加给它。

引用紧贴其直接支撑的论断，避免段末堆列多篇。综合比较和本文设计的依据可以保留在逐段溯源，不用一组论文替整段背书。文献比例分别报告全部CCF A/B、非理论文献的年份合规比例及预印本占比；按本稿引用用途，ReAct、Reflexion及排序学习、图表示、自注意力等基础机制计入理论/基础文献。
