# 智能体失败诊断与执行恢复的确定方案

本次以已经跑出效果的实验为依据重写研究方案，修正了V2把数据来源与候选清单混在一起、题目突然转向软件任务以及图表格式不合适的问题。研究对象统一为智能体失败诊断与执行恢复，软件仓库明确为当前验证场景。

## 已确定的内容

表1 本次确定的研究方案

| 项目 | 明确决定 |
|---|---|
| 题目 | 基于学习排序的智能体失败诊断与执行恢复方法研究 |
| 研究结构 | 一个总体目标、两个研究目的、两个研究问题；整体与机制实验均对应其中的RQ2，不增设第三RQ |
| RQ1基线 | StepFinder、All-at-Once、Binary Search；唯一预登记备选Step-by-Step |
| 整体基线 | Agentless、EnAgent、PatchPilot；唯一预登记备选SGAgent |
| 正式数据 | AFTraj为RQ1主数据；AgenTracer coding为已验证补充；SWE-Gym配套轨迹为一套恢复来源，共三套 |
| 正结果依据 | AF120为86对82/77；coding363三划分为179对150、184对156、186对159；旧七状态为5/7对0/7 |
| 图表 | 图、表按章编号；表题在上、图题在下；黑白三线表；总框图用蓝橙双列和有意义的分支 |

“主备选择确定”不等于所有方法已经取得有效运行资格。SBS当前没有可启用的非零定位结果，PatchPilot和SGAgent仍需完整资格验证；这些事项明确交给下一部分，不填成零分或已完成成绩。
