## 二、主要修订

摘要和研究目标直接说明两项研究做什么。背景段落保留从大语言模型到智能体的过渡，减少重复的承接语。研究现状集中介绍已有工作，原理依据仍在方法及评价章节对应位置引用。

正文已删除对译名使用习惯的评论。排序学习直接作为研究概念使用，并说明候选评分函数、训练目标与排序输出的关系，相关参考文献继续保留。

方法部分明确初始表示、关系增强表示和步骤上下文的作用，评分输入中的差值写明为关系增强表示与步骤上下文之差。历史编辑、当前代码和候选状态分别按实际对象表述。

难点部分用具体问题替代抽象判断，说明有限监督下的证据利用、关系重合与计算开销、历史步骤与当前代码的对应，以及进展保持对后续修复的限制。对尚待实验判断的候选效果保留开放表述。

实验和前期结果部分区分完整系统比较、排序替换及模块消融；同一组数字继续对应原有方法、数据和实验条件。条件续跑明确交代取消原外部时间限制和通用接口修复，保留对结果解释有影响的条件。

## 三、术语对应

| 表达 | 使用范围 |
| --- | --- |
| 失败诊断 | 分析已经失败的执行轨迹，输出责任步骤排序 |
| 责任步骤排序 | 根据轨迹内评分给出历史步骤的检查次序 |
| 失败任务恢复 | 从失败代码和环境出发，利用诊断信息继续修正原始任务 |
| 恢复成功 | 最终交付通过规定的独立验收 |
| 初始表示 | 步骤编码及投影得到、经旁路进入评分器的表示 |
| 关系增强表示 | 经过多关系门控传播更新后的步骤表示 |
| 步骤上下文 | 针对待评分步骤聚合全轨迹信息得到的上下文 |
| 共享查询上下文对照 | 用轨迹均值生成共享查询，并保留注意力修正；对应既有静态共享查询对照 |
| 轨迹均值上下文 | 直接以轨迹均值作为上下文；对应w/o StepCtx |
| 可用历史编辑 | 成功执行、实际修改许可源码并经去重后保留的历史编辑 |
| 独立验收 | 与生成反馈隔离、用于评价选定交付的测试 |

“累积”用于描述错误或操作影响逐渐积聚，“累计”用于已经通过的测试项及资源统计。候选补丁、候选代码状态和候选步骤各指不同对象，按上下文分别使用。
