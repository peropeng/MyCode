# 开题报告前三章：逐页论述溯源

采用题目：**基于多关系图建模的智能体细粒度责任排序和状态恢复方法研究**。

对应文件：[前三章HTML演示稿](开题报告_HTML_前三章演示版.html)。本索引按当前35页版本组织，记录文献概念、本研究定义、实现依据与预期结论的对应关系。表中“整页”包括引导句、分节正文、图表标签、公式解释与页末限定语。封面、章节页和纯导航文字不承担学术论断。第三章另附[逐页讲稿与术语备注](第三章_讲稿与术语备注.md)。

## 一、论述性质与引用边界

文献论断依据论文原文；本研究的方法定义与实现依据冻结协议和实际代码。研究动机属于对问题与方法关系的分析，不将其写成已经得到实验支持的普遍结论。第12、15页的效果表述明确属于预期结论，本版本不报告未经逐项核验的实验提升数值。

“细粒度责任排序”是本文结合步骤归因与排序学习建立的任务定义，不是某篇论文已经给出的统一术语。“多关系图”采用已有关系图定义，但四类步骤关系和两轮固定聚合属于本文设计。“状态恢复”借鉴回滚恢复与事务无回归思想，具体验收条件由本文执行环境规定。

## 三、本研究方法的可核查来源

以下标识仅用于此索引，不放入演示稿正文。

- **M1：RQ1纠正式协议。** [实验112C协议](../../实验/实验112C_RQ1时序依赖排序纠正式复跑/protocol.json)。`data_and_split`约束任务组划分与严格内层折外预测；`representation_and_graph`规定23维初始表示、四类关系、两轮无参数聚合和215维图特征；`optimizer_and_score`规定成对学习、分数和并列规则；`stacking`规定融合特征与消融。纠正式结果优先于原实验112的旧结果。
- **M2：实际图构造与排序实现。** [实验112固定实现](../../实验/实验112_RQ1时序交互依赖完整排序/runner.py)。实验112C只读调用此实现。`_aggregate_graph`逐关系计算均值并进行两轮残差更新；`fit_b2_model`构造标注责任步骤与其余候选的双向差分样本；`_fit_pairwise_model`调用逻辑回归优化器。仅用该文件核对方法，不引用原实验112的旧结果。
- **M3：诊断到恢复的资产映射。** [实验113协议](../../实验/实验113_RQ2事务恢复资产对齐门/protocol.json)。`record_reconstruction`明确恢复资产为`single assistant action stream`；步骤仅保留匿名结构，图采用与RQ1一致的四类关系。步骤与候选映射要求完整排列。该来源直接限定第4页的恢复场景范围。
- **M4：候选独立工作副本。** [实验113J协议](../../实验/实验113J_RQ2资产门逐臂新克隆隔离纠正/protocol.json)及[说明](../../实验/实验113J_RQ2资产门逐臂新克隆隔离纠正/README.md)。恢复候选逐个使用独立克隆，隔离不同尝试的状态。
- **M5：依赖范围、实际重放与验收。** [实验120协议](../../实验/实验120_RQ2依赖闭包回滚Oracle上界资格/protocol.json)及[实现](../../实验/实验120_RQ2依赖闭包回滚Oracle上界资格/runner.py)。同目标前向关系生成恢复切片；等规模对照匹配省略增量数量并保持前向顺序；`_replay`保留调用位置并抑制选定增量；验收联合使用非目标状态一致性、差分检查和无新增冲突。
- **M6：恢复侧候选次序与范围组合。** [实验121协议](../../实验/实验121_RQ2原生恢复排序依赖切片/protocol.json)。`research_story.module_a`明确保护RQ1首位，后续候选按外层训练任务得到的冻结后验排序；`fairness`规定预算、候选池及隔离条件；`dependency_pool`规定范围对照。
- **M7：完整排序的独立下游效用。** [实验122协议](../../实验/实验122_RQ1完整排序到RQ2恢复桥接验证/protocol.json)及[注册对照说明](../../实验/实验122_RQ1完整排序到RQ2恢复桥接验证/README.md)。分别比较原始完整排序、保护首位后的恢复后验排序、保护首位后的固定尾序、完整次序置乱，以及无RQ1对照。在相同范围池内比较次序，另设范围规模与依赖身份对照。

M1、M2中的图关系包含前后邻接，研究对象是完整失败轨迹。所谓不可使用未来信息，在本稿中不解释为只能使用在线前缀；不可使用的是不属于当前可观测轨迹的结果泄漏及测试标签。恢复候选必须在测试结果揭示前冻结，具体边界由M3、M6、M7限定。

## 五、对题目研究范围的界定

本文包含多智能体研究，但现有两章证据覆盖范围并不相同。RQ1以多智能体轨迹为主要诊断对象，RQ2在单助手的软件工具执行环境中验证可检查的状态恢复。因此采用“智能体”这一上位范围能够同时覆盖两章，而“多智能体状态恢复”仍需增加多写入主体、跨主体状态依赖和协调恢复的实际验证。

本文的三个题目要素构成明确的方法关系：多关系图建模提供跨步骤表示；细粒度责任排序产生全步骤诊断优先级；状态恢复依据诊断与恢复侧选择规则构造并验证状态干预。三者并非三项平行任务，图建模属于RQ1的方法基础，RQ1与RQ2通过只读诊断接口衔接。
