# 开题报告第一章定稿包

## 冻结口径

- 论文题目：**智能体系统失败诊断与可靠恢复方法研究**
- RQ1：**如何利用执行轨迹中的局部行为证据与跨步骤关联，对智能体任务失败进行细粒度责任定位？**
- RQ2：**如何利用失败诊断结果生成、选择并验证恢复方案，提高智能体系统的任务恢复能力并降低错误干预风险？**
- 题目和 RQ 不写“面向有状态工具调用”。有状态工具调用是恢复方法的现实约束与实验场景，不是研究问题边界。
- 研究现状严格使用直接对应 RQ1/RQ2 的 5+5 篇论文；核心方法来源和本文借鉴关系只在科普说明中单列，不倒推研究现状。

## 文件

- `第一章绪论_研究生扩展版.md`：约 2.3 万字符的研究生论文第一章 Markdown 初稿，按 10 个一级小节和 42 个三级小节展开；当前优先审内容，确认后再回填 LaTeX。
- `chapters/chapter1.tex`：可直接放入武汉大学论文模板的第一章“绪论”。包含研究背景、5+5 篇研究现状、研究缺口、两个 RQ、方法、消融口径、前期结果、创新点和章节结构。
- `bibs/ref1.bib`：第一章 10 篇研究现状论文的 BibTeX，字段来自正式出版页或正式 DOI 元数据。
- `研究现状与技术设计科普说明.md`：面向作者的概念、论文结论、借鉴边界、A/B/C 技术原理、消融话术和导师问答。

## 放入武汉大学模板

本包遵循 [iamywang/whu-thesis-latex-template](https://github.com/iamywang/whu-thesis-latex-template) 的目录和引用方式。模板使用 BibTeX 与 `gbt7714-numerical`，参考文献按 GB/T 7714—2015 数字顺序制排版。

将两个文件复制到模板相同位置：

```text
whu-thesis-latex-template/
├── chapters/
│   └── chapter1.tex
└── bibs/
    └── ref1.bib
```

确认主文件包含：

```tex
\include{chapters/chapter1}
\bibliographystyle{gbt7714-numerical}
\bibliography{bibs/ref1}
```

模板官方给出的编译方式：

```text
XeLaTeX → BibTeX → XeLaTeX → XeLaTeX
```

或：

```bash
latexmk -xelatex thesis.tex
```

最终提交前仍需以学院最新格式要求和学校官方模板为准。

## 研究现状与方法来源的区别

第一章的 5+5 篇论文回答：

- 这个研究问题是否真实存在；
- 近两年同行做到了什么；
- 现有工作还缺什么。

科普说明中的核心方法论文回答：

- 本文某项设计受什么理论或经验启发；
- 借用了什么原则；
- 与原论文有什么区别，不能越界声称什么。

二者不能混写成“因为本文有 A/B 两个模块，所以各找几篇论文来对应”。
