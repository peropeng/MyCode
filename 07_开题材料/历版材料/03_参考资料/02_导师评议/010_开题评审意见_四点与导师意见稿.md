# 开题报告评议意见与导师建议

## 开题报告评议小组成员提出的意见与建议

1. 开题报告中选题意义的表述还不够集中，建议围绕拟解决的问题说明研究的必要性，进一步凝练研究目标，突出重点、分清主次，调整章节标题层次，文献引用位置要明确。
2. 研究现状应加强评述，重点分析已有方法的不足，说明自己的改进。建议用对比表分别梳理根因排序、故障恢复的主流方法，列出技术原理、优点、不足及对应文献，删减无关内容。
3. 研究内容部分应讲清研究思路和创新之处，进一步说明根因排序与故障恢复的关系，并写清拟开展的具体工作。
4. 实验设计应写得更具体。研究还没做，不宜先写自身研究的不足。
## 导师意见

1. 应根据评议小组意见，优先修改完善用于提交和存档的开题报告正文，再据此调整汇报PPT。

2. 开题报告应立足开题阶段，说明拟开展研究的总体安排及其可行性，不宜过多展开后续工作的具体实施细节，也不要加入与开题无关的内容。

3. 开题报告应说明预期研究效果的实际意义，不能只强调指标有所提高，还应论证提高后的效果是否具有实际应用价值。
