# 开题报告评议小组成员提出的意见与建议：

1. 选题意义的表述还不够集中，建议围绕研究要解决的问题展开，说明开展这项研究的必要性，研究目标也应适当凝练。报告和PPT要突出重点、分清主次，文献引用位置要明确。

2. 文献综述应加强评述，着重分析已有方法的不足，说明本课题准备在此基础上作出哪些改进，与研究关系不大的内容可以删减。

3. 本课题应当说明根因排序有哪些创新，后面的故障恢复与前面的排序是什么关系、两项研究工作的关系还需进一步说明，尤其是根因排序如何支撑后续的任务恢复，应把自己的研究思路和创新之处讲清楚。

4. 实验设计应写得更具体，实验设计要把数据集、指标和运行环境分条列出。研究还没做，不宜先写自身研究的不足。
